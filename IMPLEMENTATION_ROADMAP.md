### 1. Frontend Deployment (Vercel) - WEEK 1

### 8. Email Setup - WEEK 3

#### SendGrid (Transactional Email) - FREE
```bash
# 1. Create account
# https://sendgrid.com/

# 2. Get API key
# Settings → API Keys → Create API Key

# 3. Install SDK
npm install @sendgrid/mail

# 4. Add to environment
SENDGRID_API_KEY=SG.xxx

# 5. Verify sender email
# Sender Authentication → Verify Domain (SPF/DKIM)

# Usage in code:
import sgMail from '@sendgrid/mail'
sgMail.setApiKey(process.env.SENDGRID_API_KEY)
await sgMail.send({
  to: 'user@example.com',
  from: 'noreply@listingko.com',
  subject: 'Welcome',
  html: '<h1>Welcome</h1>',
})
```

**Cost:** FREE (100 emails/day)
**Setup Time:** 30 minutes
**Use Case:** Order confirmations, marketplace notifications

## When to Upgrade

**Upgrade Supabase to Pro when:**
- Database: >500MB data
- Bandwidth: >2GB/month
- Need automatic daily backups
- Need priority support

**Upgrade Stability AI when:**
- >5,000 images/month
- Need faster generation
- Need priority support

**Upgrade monitoring when:**
- >10k events/day
- Need advanced analytics
- Need custom dashboards
